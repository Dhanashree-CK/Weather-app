# Weather-app

Yours Truly Weather

A sleek weather web app built with Python (Flask) that shows the current weather and a 5-day forecast for any city .
Powered by the OpenWeatherMap API.

Live Demo: https://weather-app-2uah.onrender.com

Features
Search weather by city name
Current temperature
Humidity details
Clear condition description (Rain, Sunny, Cloudy etc.)
5-day forecast (one summary per day)

Tech Stack
Backend: Python + Flask
Frontend: HTML, CSS API: OpenWeatherMap

Deployment
This project is deployed on Render.
Anyone can try it here - Yours Truly Weather
